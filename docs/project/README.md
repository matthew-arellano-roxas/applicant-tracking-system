## Project documentation

The accompanying project paper covers:

1. Brief description, background, respondents, and interview guidelines
2. Cause-and-effect analysis
3. Project schedule and network layout
4. Program Evaluation Review Technique (PERT)
5. Functional analysis
6. Object-oriented design and programming
7. Conclusion and recommendations
8. Team biographies

The design artifacts include a 6M fishbone diagram, a four-week project schedule and network layout, a PERT activity sequence, use case diagram, context diagram, data flow diagram, class diagram, and system flow diagram.

The PERT activities cover planning, requirements gathering, system analysis and design, database design, development, testing, debugging, documentation, and final evaluation. The object-oriented design covers users and roles, departments, staffing requests, job posts, applications, CV screening, interviews, evaluations, and hiring recommendations.
